# Paradise Nursery Shopping Application

An online e-commerce web application built with React and Redux Toolkit for browsing and purchasing various house plants, including aromatic and medicinal plants.

## Features
- **Landing Page**: Engaging introduction with a "Get Started" button.
- **Navigation Bar**: Seamlessly switch between Landing Page, Product Listing, and Shopping Cart, with a live cart item counter badge.
- **Product Catalog**: Plants categorized into sections (e.g., Aromatic Plants, Medicinal Plants) with descriptions, images, prices, and an "Add to Cart" button.
- **Shopping Cart**: Manage selected plants, adjust quantities (increment/decrement), remove items, view unit and total costs, and proceed to checkout.
